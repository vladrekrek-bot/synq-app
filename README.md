# SYNQ — телефон + компьютер

Демо-версия приложения, которое связывает iPhone и Windows-ПК: перенос фото и файлов перетаскиванием, уведомления с телефона на компьютере, ответы с ПК. Стеклянный интерфейс, без масштабирования.

## Скачать
Все сборки — во вкладке **Releases** (собираются автоматически при каждом изменении):
- 📱 **SYNQ.ipa** — открыть на айфоне в **ESign**, подписать и установить
- 💻 **SYNQ-Windows.exe** — просто запустить

## Состав
- `www/index.html` — само приложение
- `electron/` — оболочка для Windows
- `capacitor.config.json` — оболочка для iOS
- `.github/workflows/build.yml` — сборка .ipa и .exe
